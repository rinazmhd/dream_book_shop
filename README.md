# Dream Book Shop - Data Analysis Application

A Python-based data analysis application developed as part of a university
Object-Oriented Programming project.

## Features

- Admin login authentication
- CSV dataset loading
- Dataset cleaning
- Publication trends analysis
- Top 5 prolific authors analysis
- Language distribution analysis
- Publisher analysis
- Missing ISBN analysis
- Data visualisation using charts

## Technologies

- Python
- Pandas
- Matplotlib
- Object-Oriented Programming
- Strategy Design Pattern

## How to Run

Install the required libraries:

pip install pandas matplotlib

Then run:

python dream_book_shop.py
